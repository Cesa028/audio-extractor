Licenza / License:  GNU Lesser General Public License v3 (LGPL-3.0)

Sito / Website:     https://www.qt.io  ·  https://doc.qt.io/qtforpython/

Le librerie Qt sono collegate dinamicamente e installate come file .dll
separati (cartella "_internal\PySide6"): possono essere sostituite con altre
versioni compatibili, come previsto dalla LGPL v3. Il codice sorgente completo
di Audio Extractor e lo script di build sono inoltre nella cartella "source".
Qt libraries are dynamically linked and installed as separate .dll files
("_internal\PySide6" folder), so they can be replaced with compatible versions
as the LGPL v3 requires. The complete source code of Audio Extractor and its
build script are also included in the "source" folder.
